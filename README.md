# Universal Dotfiles

Configurações pessoais compartilhadas entre computadores, mantidas com um repositório Git *bare*.

- Histórico Git e remoto: `~/.universal-bare-repo`
- Área de trabalho: `$HOME`
- Arquivos auxiliares: `~/.universal`
- Skills do Codex: mantidas fora deste repositório

## Documentação

O guia de instalação, organização e manutenção está em [`.universal/README.md`](.universal/README.md).
